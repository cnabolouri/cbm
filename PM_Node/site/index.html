PM Node

Four inspection instruments in one handheld node.

Vibration, thermal, probe temperature and sound on one ESP32-S3 device, with an on-board TFT, a rotary interface, microSD recording and a local web UI over its own access point.

More time is spent switching devices than analysing machine condition, and the captures never line up.

The node

Six sensors, one board
IIS3DWBVibration + FFTPer-axis velocity, dominant frequency, harmonic detection.
MLX90640Thermal camera32 × 24 at 2 Hz with hotspot tracking and threshold regions.
DS18B20Probe temperatureContact reference the thermal delta is measured against.
I2S MICSound + spectrum16 kHz level and 256-point FFT with a character classification.
ST7796 + KY-040On-device UI480 × 320 TFT, eight pages, one rotary encoder.
microSD + APRecord & serveCSV at 20 Hz, WAV audio, and a web UI over its own access point.

Where it stands

Hardware revisions, in order
Rev 01Display replaced — moved to the ST7796.
Rev 02Joystick removed; pointer-driven navigation dropped.
Rev 03KY-040 rotary encoder adopted as the single control.
Rev 04Vibration sensor replaced with the IIS3DWB.
Rev 05SPI bus conflicts resolved between the display, sensor and SD.

Core sensing, TFT navigation, local web serving, recording toggles and the analysis pages are implemented or partially implemented. Active development.
