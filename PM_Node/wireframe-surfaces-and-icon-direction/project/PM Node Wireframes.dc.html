D — Rules the build should hold

Trust before valueAny page showing analysis output states its mount state first. An untrusted reading is shown dimmed with the reason, never hidden and never presented as fact.
One record stateEncoder press and web button drive the same RecordingMode. The web UI polls /api/status so it never shows a stale state after a press on the device.
Thumb-sized targets46–48 px minimum on every control. The user is standing, one-handed, possibly gloved.
No frameworks on devicePages are served as strings from web_ui.cpp. Layout is CSS grid, charts are inline SVG or canvas, polling is fetch — nothing that needs a CDN the AP cannot reach.
Dark theme on deviceThe web UI should ship the dark ground (#1D2D3D) to match the TFT and survive daylight glare. These wireframes are drawn light for print and review.
Units on every numberin/s, g, °F, dB, Hz. The firmware mixes them freely; the UI never does.
